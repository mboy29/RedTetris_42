# Red Tetris

**Validated at 125%**

A real-time multiplayer Tetris game built with **JavaScript**, **React** and **Node.js**.

The application uses **Socket.IO** for bidirectional communication between the client and server. It features competitive multiplayer gameplay, synchronized game states, animations, line clearing and automatic game-over detection.

## Key Features

- **Real-time multiplayer:** Play against other users and follow their progress live.
- **Competitive mechanics:** Send penalty lines to opponents by clearing multiple lines.
- **Tetris gameplay:** Gravity, movement, rotation, collision detection and line clearing.
- **Client-server architecture:** Asynchronous communication using Socket.IO and a REST API.
- **Single-page application:** React interface with Redux for application state management.
- **Automated testing:** Jest unit tests with at least 70% statement coverage.

## Additional Features

- **Scoring system:** Earn points for cleared lines, with additional rewards for doubles, triples and Tetrises.
- **Rankings:** Compare scores and compete against other players.
- **Sprint mode:** Play at an increasingly faster pace as the level progresses.
- **Training mode:** Practise freely without affecting scores or rankings.
